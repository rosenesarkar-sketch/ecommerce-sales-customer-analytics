# E-Commerce Sales, Customer & Delivery Analytics
# Project Overview

An end-to-end e-commerce data analytics project using the Brazilian Olist public dataset. The project explores sales performance, customer purchasing behaviour, product trends and delivery performance using Python and SQL in Google Colab.

# Tools & Technologies

Python

Pandas and NumPy

Matplotlib

SQL and SQLite

Google Colab

GitHub

# Key Analysis

Overall sales and business KPIs

Monthly revenue trends

One-time vs repeat customer analysis

Highest-spending customers

Product and category performance

Order and delivery performance

SQL-based business queries

# Key Findings

Total Orders: 99,441

Total Product Revenue: R$13,591,643.70

Average Revenue per Order: R$137.75

Unique Customers: 96,096

Total Items Sold: 112,650

On-time or Early Deliveries: 88,649

Delayed Deliveries: 7,827

Customer Split: 96.9% one-time and 3.1% repeat customers

# Files Included

Ecommerce_Sales_Analysis.ipynb – Google Colab notebook containing the analysis and SQL queries.

Olist_Final_Analysis.csv – Final analysis output.

Olist_One_Page_Project_Report.docx – Project summary report.

# Dataset

Brazilian Olist E-Commerce Public Dataset: Kaggle Dataset

# Conclusion

This project demonstrates practical skills in data cleaning, exploratory data analysis, SQL querying, KPI development, data visualisation and business insight generation. The workflow and analytical methods can be applied to retail and e-commerce business problems.
